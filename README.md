# 炸彈超人對戰 — 自架連線版

誰都能進來，**不需要登入、不需要任何帳號**。把邀請連結傳出去就能一起玩。

跟 Claude artifact 版的差別：那一版的即時連線只接受同一個組織的帳號，
所以外面的朋友永遠連不進來。這一版走自己的 WebSocket，沒有這個限制。

---

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲本體，單一檔案 |
| `server.mjs` | 網頁伺服器 ＋ 房間中繼（同一支程式） |
| `package.json` | 只有一個相依套件 `ws` |

伺服器**不懂遊戲規則**，只負責把每個人的狀態轉給同房間的其他人。
實際運算由房主那台電腦做，所以這支很輕，免費方案就跑得動。

---

## 快速上手

```powershell
cd bomber-online
.\start.ps1           # 本機 ＋ 同一個網路的人可以玩（最穩）
.\start.ps1 -Public   # 另外開一條臨時公開網址（外面的朋友可以玩）
.\stop.ps1            # 全部關掉
```

`-Public` 會**等 DNS 真的生效才把網址印出來**，印出來就是能開的。

## 一、先在自己電腦上跑跑看

```bash
cd bomber-online
npm install
node server.mjs
```

開 <http://localhost:8787> 就能玩。

**同一個區域網路的人**（家裡的其他電腦、手機）可以用你的內網位址連進來：

```powershell
# 查自己的內網 IP
ipconfig | Select-String IPv4
```

然後他們開 `http://192.168.x.x:8787`（換成你查到的位址）。
Windows 第一次跑會跳防火牆詢問，要按「允許」。

## 二、讓網路上任何人都能連（選一個）

### 方案 A：Render（免費、最省事、**網址永遠不變**）← 建議

資料夾裡已經放好 `render.yaml`，所以不用手動填任何設定。

1. 把 `bomber-online` 這個資料夾推上 GitHub。
2. 到 <https://render.com> → New → **Blueprint** → 選那個 repo。
3. 按下去，等它跑完。

完成後會給你一個固定網址，像 `https://bomber-online.onrender.com`。
**這個網址不會變、也不用你的電腦開著**，比臨時通道可靠太多。

WebSocket 走 `wss://`，程式會自己判斷，不用改任何設定。

> 免費方案閒置 15 分鐘會休眠，下次有人開會等 30 秒左右才醒。

### 方案 B：Railway / Fly.io

一樣是 Node 專案，`node server.mjs`，`PORT` 會由平台給，程式已經讀了。

### 方案 C：不想架，只想臨時玩一次

```powershell
.\start.ps1 -Public
```

會印出一個 `https://xxxx.trycloudflare.com` 網址。

**臨時通道的實際限制**（實測踩過的）：

- 網址**每次重開都不一樣**，沒辦法固定
- 剛建立時 DNS 要 **30～120 秒**才生效，太早傳給別人他會說「打不開」
- 連線斷掉重連時，舊網址會直接死掉，得重跑
- 你的電腦關機或睡著就沒了

所以只適合「約好現在一起玩一場」。要常玩請用方案 A。

## 三、怎麼玩

1. 打開網址，網址列會自動帶一個房間代碼，例如 `?r=K7M2P`。
2. 在**「你的名字」**填自己的名字（會記在瀏覽器裡，下次還在）。
3. 按**「複製邀請連結」**傳給朋友。開同一個代碼的人就在同一場。
4. 大廳名單看得到誰進來了、誰是房主（**第一個進房的人是房主**）。
5. **房主按「開始對戰」，所有人一起進場**。沒坐滿的位子由電腦補。

想跟別人分開玩，就在「房間代碼」欄位換一個代碼再按「切換房間」。

### 操作

| | 移動 | 放炸彈 | 技能 |
|---|---|---|---|
| 玩家 1 | `W A S D` | `空白` | `K` |
| 玩家 2（同機） | `↑ ← ↓ →` | `Enter` | `/` |

連線的人各自都是「玩家 1」，用 `WASD` 就好。

---

## 四、大廳上的連線狀態

| 顏色 | 意思 |
|---|---|
| ✓ 綠 | 連線正常，顯示現在有幾個人 |
| ◐ 黃 | 連上伺服器了，但只有你一個人 —— 把邀請連結傳出去 |
| ✕ 紅 | 還沒連上伺服器，會自動重試（訊息會寫原因） |

朋友的名字**有出現在名單上**才算真的連上了，這是最可靠的判斷方式。

---

## 五、限制

- 一間房最多 **8 人**（遊戲本身最多 6 個座位）。
- 運算在房主那台，所以**房主的網路品質決定整場的順暢度**。
- 房主離開後，剩下的人裡會自動推一個新房主，但進行中的那一局會亂掉，建議重開一局。
- 斷線會自動重連（最多每 8 秒試一次）。

## 十六張（台灣麻將）連線

同一台伺服器就順便發這款，網址是 `/mahjong.html`。

- **開房間**：直接打開 `/mahjong.html` 就會自動幫你開一間，網址列會多一段 `?r=房號`。
  也可以在右側「連線對戰」面板按「開一間新房間」，或輸入別人給的房號按「加入」。
- **取名字**：面板最上面的輸入框，最多 8 個字，會記在這台瀏覽器裡，下次打開還在。
- **邀請**：按「複製邀請連結」把網址傳給朋友，他們打開就跟你同一桌。
- **人不夠**：空位由電腦頂著，隨時有人進來就接手那個位子。
- **中途離開**：按「我有事，請電腦代打」，那一席交給電腦，回來按「我回來了」就收回去。
  直接關視窗或斷線也一樣會自動代打，不會卡住整桌。太久沒動作（預設 45 秒）會先幫你打這一手。
- **暗牌**：房主那台跑規則，每個人只收到自己看得到的畫面 —— 別人的手牌根本不會傳到你的瀏覽器，
  所以打開開發者工具也看不到別人的牌。

注意：**房主（第一個進房間的人）離線的話，那一局救不回來**，會由下一個人接手並重新發牌。
牌牆與四家的暗牌只存在房主那台，換人就沒了。
